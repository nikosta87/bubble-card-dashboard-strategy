# Release Roadmap

The 14 feature goals are grouped into five testable packages. Each package receives its own version, release notes, and documentation. Development continues after the previous package has been tested in a real Home Assistant installation.

## Package 1 - Bubble-native control foundation

Status: Included in v0.22.0

- Smart room cards on the Home screen
- Bubble Card sliders and select sub-buttons
- Generated camera pop-up
- Bubble Card 3.2 adaptive and performance-oriented pop-ups

Related feature goals: 1, 4, 8, and 9.

## Package 2 - Adaptive home intelligence

Status: Planned

- Context-aware room prioritization
- Extend the existing summaries into an exception-first status bar
- Daily-life cards for calendars, waste collection, appliances, energy, and active tasks

Related feature goals: 2, 6, and 11.

## Package 3 - Configuration and personalization

Status: Planned

- Expand the existing graphical editor into focused configuration panels
- Per-user profiles and visibility
- Extension slots for custom cards, sections, and pop-ups

Related feature goals: 3, 10, and 12.

## Package 4 - Design system and responsive layouts

Status: Planned

- Bubble Card modules and reusable design presets
- Dedicated mobile, tablet, and desktop layout profiles
- Native card sizing with reduced card-mod dependency

Related feature goals: 5 and 13.

## Package 5 - Complete dashboard platform

Status: Planned

- Expand the existing summary pop-ups into dedicated lights, climate, covers, security, batteries, and media overviews
- Dependency checks, onboarding, diagnostics, and debug reports

Related feature goals: 7 and 14.
